## 一、项目信息

- 项目名称：AI 求职面试助手

- 技术栈：Python + Streamlit + DeepSeek（可切换 OpenAI 等兼容平台）
- 开发周期：2026-08-04 至 2026-09-21（提交期 09-22 至 09-30）

## 五、决策记录

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-08-04 | 采用 DeepSeek 作为默认模型，接口层可切换 | 国内直连、延迟低、性价比高 |
| 2026-08-04 | 第一版纯文字，不加语音 | 一个月内保证完成度 |
| 2026-08-04 | 免费部署 + 本地运行兜底 | 确保国内环境可访问且不花钱 |
| 2026-08-04 | v0.2 模拟面试加入"一次一问、答后可追问"机制 | 行业最佳实践：真实面试官会针对空泛回答追问细节 |
| 2026-08-04 | v0.2 简历诊断加入"岗位要求 × 简历证据 × 证据强度 × 缺口"对照表 | 行业最佳实践：先对照岗位找证据缺口，禁止 AI 推测虚构 |
| 2026-08-05 | 真机验证通过，确认 `deepseek-v4-flash` 输出稳定 | 评分范围正确、JSON 格式稳定、全流程约 27 秒 |
| 2026-08-05 | 用户信息采集改为"AI 先提取简历缺失项，再列表询问用户" | 比强制填表更自然，信息只用于简历优化 |
| 2026-08-05 | 模型输出上限统一提高到 8192 tokens | 长优化方案曾被截断导致解析失败 |
| 2026-08-05 | AI 返回格式异常时自动重试一次 | 模型偶发输出非 JSON，重试可显著降低失败率 |
| 2026-08-05 | 追问机制限定每题最多一次 | 平衡真实感与流程复杂度 |
